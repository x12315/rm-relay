# 社区工作

GitHub 是 RM Relay 的主仓库。项目方向、代码、文档和待办事项都以这里的记录为准。

## 服务

项目希望战队自行托管长期使用的镜像和编译服务。公共快速体验服务器尚未上线，未来由
[@x12315](https://github.com/x12315) 维护，用于降低第一次试用的门槛，不承诺生产级
可用性。项目也会评估开源平台提供的免费云能力，但不会让基本开发途径依赖单一服务。

## 仓库外工作

RM 论坛发布、试用队伍联络和贡献者招募属于项目工作。长期目标写入
[路线图](../../ROADMAP.md)，具体工作使用 GitHub Issue 记录目标和完成条件；活动结束后，
将外部链接、结果与后续事项写回 Issue。这样，仓库之外完成的工作也能被后续维护者接手。

参与代码、文档或验证工作，见[贡献指南](../../CONTRIBUTING.md)。项目为何选择共同维护
开发基础设施，见[项目背景](why-rm-relay.md)。
